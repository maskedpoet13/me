# ME

A personal saving layer that will grow into a talkable twin. See `SPEC.md` for the full plan, `CLAUDE.md` for working rules, and `STATUS.md` for progress.

## Run locally

```bash
cp .env.example .env.local   # then fill in the values
npm install
npm run dev
```

Checks: `npm run typecheck`, `npm test`, `npm run build`.
